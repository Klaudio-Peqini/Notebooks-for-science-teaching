# Scientific Jupyter Notebooks for Teaching
### Interactive Computational Physics, Mathematics, and Data Science

---

## Overview

This repository contains a curated collection of **Jupyter Notebooks designed for science teaching**, with a primary focus on:

- Physics
- Applied Mathematics
- Computational Modeling
- Data Analysis
- Scientific Programming with Python

The notebooks are intended to serve as:

- Teaching material for undergraduate and graduate courses
- Interactive lecture demonstrations
- Self-study resources for students
- Computational companions to theoretical lectures
- Foundations for student projects and assignments

The overall philosophy of this repository is:

> **Learning science by doing science.**

Students are encouraged not only to read but to experiment, modify, and extend the notebooks.

---

## Educational Philosophy

Traditional science education often separates:

- Theory
- Computation
- Experiment

This repository integrates all three into a unified learning experience.

Each notebook typically includes:

- Physical or mathematical theory
- Step-by-step derivations
- Python implementation
- Visualization
- Exercises
- Open-ended exploration

The goal is to develop:

- Physical intuition
- Mathematical understanding
- Computational skills
- Scientific thinking

## Requirements

Python 3.10+ recommended.

Install dependencies:

```

```

- scipy

- pandas

### Running the Notebooks

Start Jupyter:

jupyter notebook

or

jupyter lab

Navigate to the desired notebook and run the cells.
